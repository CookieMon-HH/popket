## 1. 현재 그래픽의 아쉬운 점

### 몬스터
1. **음영이 평면적이고 광원이 제각각이에요.** 몸 색 + 진한 색 + 연한 색 2~3단계를 손으로 찍어서, 종마다 빛 방향이 다르고 입체감이 약해요.
2. **모든 외곽선이 같은 남색(`#26263a`) 한 줄이에요.** 스티커처럼 보이고, 같은 색 부위가 겹치면(퐁당이 머리와 몸, 모닥뿔 머리와 몸통) 경계가 사라져요.
3. **눈이 순수 검정 블록이고 거의 모든 종이 같은 모양이에요.** 홍채 색이 없어 표정 차이가 적고, 입은 검은 점 1~3개예요.
4. **뒷모습이 진짜 뒷모습이 아니에요.** 앞모습에서 눈·입 픽셀을 자동으로 지운 것이라 자세가 같고, 지운 자리가 얼룩처럼 남기도 해요(배틀 화면 퐁당이 뒷모습의 하얀 눈 자국).
5. **뒷모습이 3.4배(40px → 136px)로 그려져요.** 정수배가 아니라 픽셀마다 크기가 3px·4px로 들쭉날쭉하고, 너무 커서 정보창·메시지창에 많이 가려져요.
6. **질감 표현이 거의 없어요.** 불꽃은 2색 덩어리, 털·비늘·바위 결은 없고, 은하고래 별은 점 하나예요.
7. **종마다 채도·밝기 기준이 달라요.** 파스텔 종과 진한 종이 섞여 도감에 모아 놓으면 통일감이 떨어져요.

### 배틀 화면
- 배경이 어느 지역이든 같은 연두색 그라데이션과 타원 발판이에요. 유령선과 리그 경기장만 예외예요.
- 내 몬스터가 화면 아래쪽에 크게 걸쳐 있어서 몸 절반이 정보창·메시지창 뒤로 숨어요.

### 필드 타일·사람
- 타일 가독성은 좋지만 **그림자가 없어요.** 건물·나무·사람이 바닥에 붙어 있는 느낌이 약해요.
- 잔디·물은 단색 + 점 무늬라 넓은 맵에서 단조로워요. 나무도 모두 같은 둥근 모양이에요.
- 사람(16×20)은 머리·옷·바지 3색에 음영이 없고, 체형이 하나뿐이에요.

### UI
- 흰 상자 + 남색 테두리로 깔끔하지만 개성이 적어요. HP 바도 평범한 막대예요.
- UI 글자는 고해상도, 게임 화면은 픽셀이라 두 층의 느낌이 조금 따로 놀아요. 이건 가독성 때문에 유지하는 쪽을 권해요.

## 2. 스타일 규칙

### 2.1 팔레트: 5단계 램프
모든 색은 **기본 색 하나에서 만든 5단계 램프**로 칠해요(`ramp(base)`).

| 단계 | 쓰는 곳 | 만드는 법 |
| --- | --- | --- |
| 외곽선 `o` | 몸 바깥 테두리 | 기본 색보다 훨씬 어둡게, 색상을 보라 쪽으로 크게 이동 |
| 어두운 색 `d` | 그림자 면, 겹친 부위 사이 안쪽 선 | 조금 어둡게, 색상을 파랑·보라 쪽으로 약간 이동 |
| 기본 색 `b` | 대부분의 면 | 기존 디자인의 몸 색 그대로 |
| 밝은 색 `l` | 빛 받는 면 | 조금 밝게, 색상을 노랑 쪽으로 약간 이동, 채도 약간 낮춤 |
| 하이라이트 `h` | 반짝이는 점(아주 작게) | 더 밝게, 노랑 쪽으로 이동, 채도 낮춤 |

- **색상 이동(hue shift)**: 그림자는 차갑게(파랑·보라), 빛은 따뜻하게(노랑). 단순히 검정·흰색을 섞으면 탁해져요.
- 한 종에 쓰는 램프는 **3~4개 이하**(몸·배·포인트 색·특수 소재)로 제한해요.
- 불꽃·용암처럼 스스로 빛나는 소재는 고정 램프를 써요(`FIRE`, `LAVA`: 진홍 → 주황 → 노랑 → 흰 노랑).
- 기존 디자인의 기본 색을 `b`로 그대로 써서, 지금 색감과 실루엣을 유지해요.

### 2.2 광원과 음영
- **광원은 왼쪽 위, 약간 앞쪽 하나**만 써요(빛 벡터 −0.55, −0.62, 0.56).
- **둥근 부위**(몸통·머리·배)는 타원체로 보고 면의 방향에 따라 `d → b → l → h`를 칠해요. 그림자는 오른쪽 아래에 생겨요.
- **납작하거나 각진 부위**(다리·뿔·가시·꼬리 지느러미)는 *베벨*로 칠해요. 왼쪽·위쪽 가장자리는 `l`, 오른쪽·아래쪽 가장자리는 `d`예요.
- **하이라이트는 부위마다 1~3픽셀만.** 너무 많으면 젤리·플라스틱처럼 보여요.
- 배·주둥이처럼 몸 위에 얹는 밝은 부위는 몸통의 입체를 따라 음영을 넣고, 따로 외곽선을 긋지 않아요.
- 멀리 있는 다리는 몸 램프의 `d`를 기본 색으로 한 램프로 칠해 원근감을 줘요.
- 디더링(점 섞기)은 40px에서 지저분해 보여서 쓰지 않고, 깔끔한 색 띠로 나눠요.

### 2.3 외곽선
- 검정 단색 테두리를 없애고, **부위마다 자기 램프의 외곽선 색**으로 둘러요(selective outline).
  모닥뿔은 적갈색, 퐁당이는 남색, 새순이는 짙은 초록 테두리가 돼요.
- 앞 부위가 뒤 부위 위에 겹치는 곳에는 **앞 부위의 어두운 색으로 1px 안쪽 선**을 그어요.
  바깥 테두리보다 옅어서 경계는 읽히고 화면이 지저분해지지 않아요.
- 마지막에 실루엣 빈틈을 이웃 색의 외곽선 색으로 메워요(`seal`).

### 2.4 얼굴
- **눈**(아기 단계, 3×4): 짙은 보라 테두리(순수 검정 금지), 왼쪽 위 큰 하이라이트 2px, 오른쪽 작은 하이라이트 1px,
  아래쪽에 **종마다 다른 홍채 색**이 은은하게 비쳐요. 귀여운 큰 눈의 인상은 유지해요.
- **눈**(최종 진화·사나운 종, 4×2): 가늘고 날카롭게, 홍채 색 + 진한 눈썹 선.
- **입**: 검정 대신 짙은 적갈색. 벌린 입 안쪽은 분홍·빨강 1~3px. 볼 홍조는 2px.
- 뒷모습에는 얼굴을 그리지 않아요.

### 2.5 질감
- **불꽃**: `FIRE` 램프 + 안쪽이 밝은 *발광 음영*(가운데·아래쪽 = 흰 노랑, 바깥 = 진홍). 끝은 뾰족한 삼각형으로 마무리해요.
- **용암·마그마 균열**: 몸 위에 `LAVA` 선을 긋고 군데군데 `h` 점으로 달아오른 느낌을 줘요.
- **바위**: 회보라 램프 + 베벨 음영, 각진 판 모양. 결 사이로 빛(용암 등)이 새어 나오게 해요.
- **털**: 실루엣 가장자리를 작은 삼각형 술로 끊고, 밝은 면에 `l` 붓질 1~2px.
- **비늘·피부 무늬**: 그림자 면에 `d` 점·짧은 호 몇 개만. 촘촘하게 다 찍지 않아요.
- **물·젤리 질감**: 둥근 음영 + 작은 하이라이트. 물방울은 위쪽 반사광을 크게.
- **별·반짝임**: 중심 1px + 십자 4px 발광(빛 번짐 색), 주변에 희미한 별 점.

### 2.6 뒷모습
- 앞모습에서 얼굴을 지우는 대신 **진짜 뒷모습을 따로 그려요.** 등에 있는 특징(모닥뿔 프릴 뒷면, 화산뿔 등판 바위, 은하고래 등의 별, 퐁당이 등 무늬)을 크게 보여 줘요.
- 실루엣과 색은 앞모습과 같아서 같은 몬스터로 바로 알아볼 수 있어요.
- **뒷모습은 오른쪽(적이 있는 쪽)을 바라봐요.** 앞모습은 왼쪽(내 몬스터 쪽)을 봐요. 뒷모습은 같은 왼쪽 배치로 그리되 빛을 거울처럼 뒤집어 칠한 뒤 좌우 반전해서, 오른쪽을 봐도 빛은 그대로 왼쪽 위에서 와요. 비교 시트의 현재 뒷모습도 배틀에 표시되는 방향(오른쪽)으로 보여 줘요.

### 2.7 크기: 40×40 유지 vs 56×56 확대

| | 40×40 유지 (권장) | 56×56으로 확대 |
| --- | --- | --- |
| 표현력 | 눈 3×4, 디테일은 핵심만 | 눈·질감·전설 몬스터의 위엄을 더 많이 그릴 수 있음 |
| 작업량 | 151종을 같은 좌표계에서 다듬기 | 151종을 새 좌표로 사실상 새로 그려야 함(약 2배 픽셀) |
| 화면 배율 | 적은 2배(80px), 나는 3배(120px)로 **정수배 유지** | 적 80px에 맞추면 1.43배라 픽셀이 들쭉날쭉 → 112px(2배)로 키우려면 배틀 배치 변경 필요 |
| 다른 화면 | 동료·도감·보관함·상점 아이콘 크기 그대로 | 아이콘에서 축소가 정수배가 아니어서 뭉개짐 → 아이콘용 그림을 따로 둬야 함 |
| 전체 톤 | 16px 타일·16×20 사람과 밀도가 비슷 | 몬스터만 정밀해져 필드·사람과 밀도 차이가 커짐 |

**권장안:** 40×40을 유지하고, 표현은 램프·음영·외곽선으로 끌어올려요.
배율은 정수배로 맞춰요. 적은 지금처럼 2배(80px), 내 몬스터 뒷모습은 136px(3.4배)에서 **120px(3배)**로요.
샘플에서는 `?art2`일 때 이 배율이 이미 적용되어 있어요. 전설 몬스터만 48×48로 크게 그리는 방안도 가능하지만,
배틀 배치 예외가 생기므로 전체 적용 뒤에 따로 검토하는 걸 권해요.
