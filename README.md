# 팜팜몬 (Pampammon)

브라우저에서 바로 플레이하는 오리지널 몬스터 수집 RPG. 몬스터, 지역, 스토리, 그래픽은 모두 이 프로젝트에서 직접 만든 것이고, 그래픽은 코드로 그린 픽셀 아트예요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 왼쪽 조이스틱 (화면 왼쪽 아무 곳이나 누르고 끌기) |
| 결정·대화 | Z / Space / Enter | A |
| 취소·메뉴 | X / Esc / Backspace | B |

## 내용

- **스토리 (해솔 지방 한 바퀴):** 솔빛마을에서 출발해 북쪽으로 올라가 별빛시까지, 다시 동쪽과 남쪽을 돌아 해솔 리그가 있는 해솔고원을 거쳐 솔빛마을로 돌아와요.
  - 1~3장: 라이벌 은재, 검은안개단과 속삭임숲·별빛동굴, 전설의 은하고래
  - 4장 「파도항구의 유령선」: 유령선에 숨은 검은안개단, 고스트 관장 달님
  - 5장 「불꽃산의 심장」: 해변길에서 불꽃석을 나르던 간부 잿빛과의 마지막 승부, 불 관장 화련, 화산 아지트에서 두목 흑영과의 결전과 그의 사연
  - 6장 「서리마을의 눈보라」: 얼음굴에서 길을 잃은 아이와 흥분한 빙산곰, 얼음 관장 서리, 그치지 않는 눈보라의 원인을 찾아서
  - 7장 「용의 마을과 여의주」: 여의주를 훔친 잔당 먹구름, 흑영의 도움, 용의 둥지, 드래곤 관장 용하
  - 해솔 리그 토너먼트: 관중이 가득한 경기장에서 16강(도전자 한결) → 8강(그림자) → 4강(용연) → 결승(은재) 4연승. 경기마다 회복, 지면 탈락, 라운드마다 대진표·환호·꽃가루·상품, 우승하면 트로피와 엔딩
  - 엔딩 이후 「수호신 전설」: 한별 박사의 전설 수첩을 받고 네 수호신을 찾아 동료로 만들어요. 설화(얼음·페어리, 서리마을 얼음굴), 철산(땅·강철, 별빛동굴 깊은 갱도), 주작(불·비행, 화련과 재대결 후 불꽃산 심장), 청룡(전기·드래곤, 세 수호신을 모은 뒤 용의 둥지). 저마다 해솔의 팀에 강한 상성이라 최종 보스 공략의 열쇠가 돼요.
  - 엔딩 이후 「천공의 신전」: 해솔고원 북쪽 천공의 길(Lv52~60 야생, 수행자 4명)을 올라 태초의 챔피언 해솔과 대결 (6마리, Lv72~80, 능력치 최대, 만능회복약 3개). 이기면 전설의 용 천지(드래곤·에스퍼)를 만날 수 있어요.
- **지역 48곳:** 전체 지도는 world-map.png
- **수련관 7곳 (모두 퍼즐):** 단단(바위·바위 밀기), 마루(물결·수문 레버), 하람(번개·전기 울타리 스위치), 달님(달빛·순간이동 발판), 화련(화염·용암 미로), 서리(얼음·미끄럼 얼음판), 용하(용린·용 석상 퀴즈)
- **특별 퀘스트:** 배지 셋을 모은 뒤 별빛시 산지기 할아버지에게 운무봉 전설을 듣고, 숲·물·바위의 세 방울을 모아 운무봉의 산군을 만나요.
- **몬스터 97종:** 동물·사물 + 속성 컨셉 (전체 그림: monsters.png, 파스텔 세트: pastel-monsters.png)
- **타입 18종:** 노말, 불, 물, 풀, 전기, 얼음, 격투, 독, 땅, 비행, 에스퍼, 벌레, 바위, 고스트, 드래곤, 악, 강철, 페어리 (상성표 `src/data/types.ts`)
- **난이도:** 첫 수련관은 스토리만 따라가도 깰 수 있고, 뒤로 갈수록 관장이 조금씩 더 강해져서 레벨업이나 새 동료가 필요해요. 수련관 앞에는 항상 스토리 구간(트레이너·간부전)이 있어서 자연스럽게 성장할 수 있어요.
- **배틀·성장:** 턴제, 상태 이상, 능력 랭크, 포획(팜팜볼), 낚시, 경험치, 기술 습득, 진화
- **팜팜 사파리 (파도항구):** 관리인 초원의 부탁으로 도망친 아기 몬스터 셋(아기유니·몽몽이·아기곰돌)을 찾아 주면 문이 열리고 입장권 3장을 받아요. 입장권(1,500원)으로 들어가 10분 동안 사파리볼 30개로 몬스터를 잡아요. 사파리 배틀은 사파리볼·먹이·진흙·도망으로 진행되고, 꼬마룡·무지개유니·설표·날개룡 같은 희귀 몬스터와 연못 낚시의 꼬마현무도 만날 수 있어요.
- **날아가기:** 달빛배지를 받은 뒤 파도항구의 바람 조련사 솔바람에게 회오리매를 보여 주면 바람피리를 받아요. 메뉴의 「날아가기」로 한 번 가 본 마을의 회복소 앞으로 바로 이동해요.
- **시작하기:** 타이틀에서 「구글로 시작하기」를 고르면 기록이 서버에 저장되어 어느 기기에서든 이어 할 수 있고, 「계정 없이 시작하기」는 이 브라우저에만 저장해요. 계정 없이 하다가도 메뉴 → 설정 → 구글 계정에서 언제든 연동할 수 있어요. 서버에는 계정 번호와 게임 기록만 보관해요. (공식 주소: https://pampammon.vercel.app)
- **낚시:** 물가를 보고 A를 누르면 낚싯대를 던지고, 찌가 출렁이며 기다리다가 입질이 오면 「!」가 떠요.
- **쓰러졌을 때:** 마지막 회복 장소로 돌아가고 소지금의 10%만 잃어요 (최대 200원 + 배지당 100원).
- **기타:** 진행에 따라 늘어나는 상점, 도감, 가방, 회복소, 트레이너 카드, 저장/이어하기(localStorage), 방향키/조이스틱 선택

## 구조

```
src/
  engine/   입력, 타이밍(tween), 렌더링 헬퍼, UI 위젯(메시지·메뉴), 픽셀 캔버스
  data/     타입 상성, 기술, 몬스터 종, 도구
  game/     맵(maps.ts), 스토리 대사(story.ts), 필드, 배틀, 메뉴, 저장 상태, 스프라이트·타일 그리기
  main.ts   게임 루프와 타이틀 화면
```

새 맵은 `src/game/maps.ts`에 타일 문자열로 추가해요. 타일 기호는 `src/game/tiles.ts`를 보면 돼요. 새 몬스터는 `src/data/species.ts`에 데이터를, `src/game/monsprites.ts`의 `MON_DRAW`에 40×40 그림을 추가하면 돼요.
