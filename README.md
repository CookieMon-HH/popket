# Popket

브라우저에서 바로 플레이하는 오리지널 몬스터 수집 RPG. 몬스터, 지역, 스토리, 그래픽은 모두 이 프로젝트에서 직접 만든 것이고, 그래픽은 코드로 그린 픽셀 아트예요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 십자 버튼 |
| 결정·대화 | Z / Space / Enter | A |
| 취소·메뉴 | X / Esc / Backspace | B |

## 첫 번째 버전 내용

- **지역:** 솔빛마을(집, 한별 연구소), 1번 도로, 들꽃마을(회복소, 상점, 수련관)
- **몬스터 16종:** 스타터 3종(모닥이·퐁당이·새순이)과 진화형, 야생 몬스터 5계열
- **타입 8종:** 노말, 불, 물, 풀, 전기, 바위, 벌레, 바람 (상성표 `src/data/types.ts`)
- **배틀:** 턴제, 기술 4개와 PP, 우선도, 급소, 자속 보정, 능력 랭크, 화상·독·마비·수면
- **포획:** 포획구·슈퍼포획구, 체력과 상태 이상에 따른 포획률, 보관함(PC)
- **성장:** 경험치, 레벨업, 기술 습득(4개 초과 시 교체 선택), 진화 연출
- **트레이너:** 시야에 들어오면 다가와서 승부, 수련관 관장전과 바위배지
- **기타:** 도감, 가방, 상점, 회복, 트레이너 카드, 저장/이어하기(localStorage), 패배 시 마지막 회복 지점으로 복귀

## 구조

```
src/
  engine/   입력, 타이밍(tween), 렌더링 헬퍼, UI 위젯(메시지·메뉴), 픽셀 캔버스
  data/     타입 상성, 기술, 몬스터 종, 도구
  game/     맵·NPC 스크립트, 필드, 배틀, 메뉴, 저장 상태, 스프라이트·타일 그리기
  main.ts   게임 루프와 타이틀 화면
```

새 맵은 `src/game/maps.ts`에 타일 문자열로 추가해요. 타일 기호는 `src/game/tiles.ts`를 보면 돼요. 새 몬스터는 `src/data/species.ts`에 데이터를, `src/game/sprites.ts`의 `DRAW`에 그림을 추가하면 돼요.
