# Popket

브라우저에서 바로 플레이하는 오리지널 몬스터 수집 RPG. 몬스터, 지역, 스토리, 그래픽은 모두 이 프로젝트에서 직접 만든 것이고, 그래픽은 코드로 그린 픽셀 아트예요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 왼쪽 조이스틱 (화면 왼쪽 아무 곳이나 누르고 끌기) |
| 결정·대화 | Z / Space / Enter | A |
| 취소·메뉴 | X / Esc / Backspace | B |

## 내용 (제3장까지)

- **스토리:** 해솔 지방. 라이벌 은재와 세 번 겨루고, 몬스터를 노리는 검은안개단을 속삭임숲과 별빛동굴에서 막아 내요. 동굴 지하 호수에서는 전설의 은하고래를 만날 수 있어요.
- **지역 21곳:** 운무봉 포함, 솔빛마을, 1번 도로, 들꽃마을, 2번 도로, 속삭임숲, 물안개마을, 3번 도로, 별빛동굴(어두운 동굴), 별빛시와 각 건물 내부
- **수련관 3곳:** 단단(바위배지), 마루(물결배지), 하람(번개배지)
- **특별 퀘스트:** 배지 셋을 모은 뒤 별빛시 산지기 할아버지에게 운무봉 전설을 듣고, 숲·물·바위의 세 방울을 모아 준전설 산군을 만나요.
- **몬스터 38종:** 대부분 3단 진화, 일부 2단 진화(토실이·찌릿이·반짝피라), 준전설 1종, 전설 1종
- **타입 11종:** 노말, 불, 물, 풀, 전기, 바위, 벌레, 바람, 독, 땅, 영혼 (상성표 `src/data/types.ts`)
- **배틀:** 턴제, 기술 4개와 PP, 우선도, 급소, 자속 보정, 능력 랭크, 화상·독·마비·수면, 회복 기술
- **포획과 성장:** 포획구·슈퍼포획구, 낚싯대 낚시, 보관함(PC), 경험치, 기술 습득, 진화 연출
- **기타:** 도감, 가방, 상점, 회복, 트레이너 카드, 저장/이어하기(localStorage)

## 구조

```
src/
  engine/   입력, 타이밍(tween), 렌더링 헬퍼, UI 위젯(메시지·메뉴), 픽셀 캔버스
  data/     타입 상성, 기술, 몬스터 종, 도구
  game/     맵(maps.ts), 스토리 대사(story.ts), 필드, 배틀, 메뉴, 저장 상태, 스프라이트·타일 그리기
  main.ts   게임 루프와 타이틀 화면
```

새 맵은 `src/game/maps.ts`에 타일 문자열로 추가해요. 타일 기호는 `src/game/tiles.ts`를 보면 돼요. 새 몬스터는 `src/data/species.ts`에 데이터를, `src/game/sprites.ts`의 `DRAW`에 그림을 추가하면 돼요.
