# 팜팜몬 (Pampammon)

브라우저에서 바로 플레이하는 오리지널 몬스터 수집 RPG. 몬스터, 지역, 스토리, 그래픽은 모두 이 프로젝트에서 직접 만든 것이고, 그래픽은 코드로 그린 픽셀 아트예요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 왼쪽 조이스틱 (화면 왼쪽 아무 곳이나 누르고 끌기) |
| 결정·대화 | Z / Space / Enter | A |
| 취소·메뉴 | X / Esc / Backspace | B |

## 내용

- **스토리 (해솔 지방 한 바퀴):** 솔빛마을에서 출발해 북쪽으로 올라가 별빛시까지, 다시 동쪽과 남쪽을 돌아 해솔 리그가 있는 해솔고원을 거쳐 솔빛마을로 돌아와요.
  - 1~3장: 라이벌 은재, 검은안개단과 속삭임숲·별빛동굴, 전설의 은하고래
  - 2장 속삭임숲: 안개와 반딧불이 떠도는 숲에서 숲의 아이들의 속삭임을 따라가 잿빛을 물리친 뒤, 깊은 숲에서 반디가 비추는 길만 따라 길 잃은 아기 몽몽이를 찾아요. 고목 공터의 둥지는 꼬마룡이 태어난 곳이에요.
  - 4장 「은파호의 수수께끼」: 30년 전 사라진 유람선 은파호. 갑판·선실·연회장·기관실·조종실·선장실을 오가며 촛불 순서 퍼즐, 밸브 퍼즐, 잠긴 문을 풀고, 가짜 유령을 꾸민 검은안개단과 진짜 유령 선장 해월의 사연을 밝혀요. 고스트 관장 달님
  - 5장 「불꽃산의 심장」: 해변길에서 불꽃석을 나르던 간부 잿빛과의 마지막 승부, 불 관장 화련, 불씨가 흩날리고 땅이 울리는 화산 아지트(바깥 동굴 → 제련소 → 화산의 심장). 제련소에서는 냉각수 밸브 세 개로 용암 수로를 식혀 길을 열고, 곳곳에 떨어진 수첩과 일기장으로 흑영이 십 년 전 숯골 마을에서 잃은 것을 알게 돼요. 일기장 속 낡은 사진을 찾아 두면 결전 뒤의 이야기가 달라져요
  - 6장 「서리마을의 눈보라」: 여의주가 돌아올 때까지 눈보라가 몰아치는 서리마을과 설원 산길. 눈송이가 떨어뜨린 장갑과 발자국을 따라 얼음굴 깊은 곳 「얼어붙은 호수」로 내려가, 9번 미끄러져야 건너는 얼음판 퍼즐을 풀고 흥분한 빙산곰을 진정시켜요. 호수 아래 고대 벽화에는 여의주와 설화의 옛이야기가 새겨져 있어요. 얼음 관장 서리
  - 7장 「용의 마을과 여의주」: 여의주를 훔친 잔당 먹구름, 흑영의 도움. 금빛 먼지와 오로라가 감도는 용의 둥지에서 바위를 밀어 길을 열고, 별자리 벽화를 보고 용의 머리·심장·꼬리 화로에 불을 밝혀 하늘의 제단 문을 열어요. 먹구름이 남긴 쪽지에는 잔당들이 매달린 이유가 적혀 있어요. 드래곤 관장 용하
  - 해솔 리그 토너먼트: 관중이 가득한 경기장에서 16강(도전자 한결) → 8강(그림자) → 4강(용연) → 결승(은재) 4연승. 경기마다 회복, 지면 탈락, 라운드마다 대진표·환호·꽃가루·상품, 우승하면 트로피와 엔딩
  - 엔딩 이후 「수호신 전설」: 한별 박사의 전설 수첩을 받고 네 수호신을 찾아 동료로 만들어요. 설화(얼음·페어리, 서리마을 얼음굴), 철산(땅·강철, 별빛동굴 깊은 갱도), 주작(불·비행, 화련과 재대결 후 불꽃산 심장), 청룡(전기·드래곤, 세 수호신을 모은 뒤 용의 둥지). 저마다 해솔의 팀에 강한 상성이라 최종 보스 공략의 열쇠가 돼요.
  - 엔딩 이후 「천공의 신전」: 해솔고원 북쪽 천공의 길(Lv52~60 야생, 수행자 4명)을 올라 태초의 챔피언 해솔과 대결 (6마리, Lv72~80, 능력치 최대, 만능회복약 3개). 이기면 전설의 용 천지(드래곤·에스퍼)를 만날 수 있어요.
- **지역 48곳:** 전체 지도는 world-map.png
- **수련관 7곳 (모두 퍼즐):** 단단(바위·바위 밀기), 마루(물결·수문 레버), 하람(번개·전기 울타리 스위치), 달님(달빛·달의 위상 수정에 따라 목적지가 바뀌는 순간이동 발판), 화련(화염·용암 미로), 서리(얼음·미끄럼 얼음판), 용하(용린·용 석상 퀴즈)
- **특별 퀘스트:** 배지 셋을 모은 뒤 별빛시 산지기 할아버지에게 운무봉 전설을 듣고, 숲·물·바위의 세 방울을 모아 운무봉의 산군을 만나요.
- **몬스터 151종:** 동물·사물·한국 민속 + 속성 컨셉. 도감 번호는 여행하며 처음 만나는 순서예요. (전체 그림: monsters.png, 파스텔 세트: pastel-monsters.png). 그림은 5단계 색 램프·왼쪽 위 광원·색별 외곽선 규칙으로 그려요(`docs/ART_STYLE.md`).
  - 유령선 은파호에는 초롱이·물귀신·해골앵무·보물상자도깨비 같은 고스트가 살고, 이야기를 끝낸 뒤에도 다시 탐험할 수 있어요.
  - 꼬리별여우는 진화의 돌(불꽃의돌·그늘의돌·가시의돌)에 따라 불여우·그늘여우·가시여우로 갈래 진화해요. 돌은 배지 4개부터 상점에서 팔고, 필드에도 하나씩 숨어 있어요.
  - 별빛동굴 화석 바위에서 껍질화석이나 날개화석을 골라 한별 박사에게 가져가면 고대조개·꼬마시조로 되살아나요.
  - 동굴과 천공의 길의 보물상자는 가끔 보물상자도깨비가 숨어 있는 함정이에요.
  - 아주 드물게 나오는 금두꺼비는 경험치를 잔뜩 주지만 몇 턴 만에 도망쳐요.
  - 선물 몬스터: 군고미·꼬리별여우(들꽃마을), 꼬마룡(속삭임숲), 오르골인형(별빛시 골동품 가게 오르골 퍼즐), 거북선(파도항구 배목수, 유령선 이후)
  - 집게사슴과 꼬리별여우 야생은 팜팜 사파리에서만 만날 수 있어요.
- **타입 18종:** 노말, 불, 물, 풀, 전기, 얼음, 격투, 독, 땅, 비행, 에스퍼, 벌레, 바위, 고스트, 드래곤, 악, 강철, 페어리 (상성표 `src/data/types.ts`)
- **난이도:** 첫 수련관은 스토리만 따라가도 깰 수 있고, 뒤로 갈수록 관장이 조금씩 더 강해져서 레벨업이나 새 동료가 필요해요. 수련관 앞에는 항상 스토리 구간(트레이너·간부전)이 있어서 자연스럽게 성장할 수 있어요.
- **배틀·성장:** 턴제, 상태 이상, 능력 랭크, 포획(팜팜볼), 낚시, 경험치, 기술 습득, 진화
- **팜팜 사파리 (파도항구):** 관리인 초원의 부탁으로 도망친 아기 몬스터 셋을 찾아 주면 열리고 입장권 3장을 받아요. 입장권(1,500원)으로 10분 동안(배틀 시간 포함) 이용해요. 광장에서 화산지대(불·땅)·푸른 호수(물)·깊은 밀림(풀·벌레)·하얀 설원(얼음)·번개 협곡(전기·강철·바위)·꿈빛 숲(페어리·에스퍼) 여섯 존으로 갈 수 있고, 배지 5개부터 희귀 몬스터가 많은 「전설의 초원」에 들어갈 수 있어요. 평소처럼 배틀해서 잡고, 레벨은 배지 수에 맞춰져요.
- **날아가기:** 달빛배지를 받은 뒤 파도항구의 바람 조련사 솔바람에게 회오리매를 보여 주면 바람피리를 받아요. 메뉴의 「날아가기」로 한 번 가 본 마을의 회복소 앞으로 바로 이동해요.
- **시작하기:** 타이틀에서 「구글로 시작하기」를 고르면 기록이 서버에 저장되어 어느 기기에서든 이어 할 수 있고, 「계정 없이 시작하기」는 이 브라우저에만 저장해요. 계정 없이 하다가도 메뉴 → 설정 → 구글 계정에서 언제든 연동할 수 있어요. 서버에는 계정 번호와 게임 기록만 보관해요. (공식 주소: https://pampammon.vercel.app)
- **낚시:** 물가를 보고 A를 누르면 낚싯대를 던지고, 찌가 출렁이며 기다리다가 입질이 오면 「!」가 떠요.
- **쓰러졌을 때:** 마지막 회복 장소로 돌아가고 소지금의 10%만 잃어요 (최대 200원 + 배지당 100원).
- **소리:** 마을마다 다른 배경음(평화로운 마을, 물가 마을, 별빛시, 불꽃마을, 서리마을, 용의 마을), 도로·동굴·사파리·회복소·수련관·리그·천공 테마, 오르골처럼 메아리치는 음산한 유령선 테마(빗속 천둥 효과음), 야생/트레이너/보스 배틀곡과 조우·타격·기절·포획·레벨업·승리·패배 효과음. 모두 코드로 합성한 칩튠이고 설정에서 끌 수 있어요.
- **기술 포인트(PP) 회복:** 기술사탕(기술 하나 PP 10, 배지 1개부터), 기술단지(기술 하나 PP 모두, 배지 2개부터), 기술꿀(모든 기술 PP 모두, 배지 3개부터)을 상점에서 팔아요. 필드와 배틀 중 가방에서 쓸 수 있어요.
- **기타:** 진행에 따라 늘어나는 상점, 도감, 가방, 회복소, 트레이너 카드, 저장/이어하기(localStorage), 방향키/조이스틱 선택

## 구조

```
src/
  engine/   입력, 타이밍(tween), 렌더링 헬퍼, UI 위젯(메시지·메뉴), 픽셀 캔버스
  data/     타입 상성, 기술, 몬스터 종, 도구
  game/     맵(maps.ts), 스토리 대사(story.ts), 필드, 배틀, 메뉴, 저장 상태, 스프라이트·타일 그리기
  main.ts   게임 루프와 타이틀 화면
```

새 맵은 `src/game/maps.ts`에 타일 문자열로 추가해요. 타일 기호는 `src/game/tiles.ts`를 보면 돼요. 새 몬스터는 `src/data/species.ts`에 데이터를, `src/game/monsprites.ts`의 `MON_DRAW`에 40×40 그림을 추가하면 돼요.
